## 2. 总体架构：玄枢主题层 `XSTheme`（运行时注入，零依赖、零构建链）

只在 `index-D5I3iBTS.js` 内做**两处定位式插入**，不新增文件、不改 css、不改主进程：

1. **主题运行时（IIFE，单例）**：就近插在现有主题模块（§1.2 `$q="theme"` 同作用域）之前/之后，启动即自执行，负责：生成并维护一个 `<style id="xs-theme-layer">`（head 末尾，保证层叠优先级）+ 一个固定背景层 `<div id="xs-backdrop">` + 全套 API 与持久化。
2. **设置面板**：在通用页 `$D` 的"外观与语言"卡片之后，定位式插入一张"外观 / 主题替换"卡片，复用现有 `F0 / HD / xa` 与原生 `input[type=color]`、Semi Button/Slider，面板只调用 `window.XSTheme.*`，不直接操作样式。

```
┌─ documentElement(html.light|dark，现有)  + data-xs-mode="glass|flat|image"（新增挂点）
│
├─ #xs-backdrop（body 下固定层：主色氛围渐变/可选图片模糊层，作为玻璃"透出来的景色"）
├─ <style id="xs-theme-layer">  ← XSTheme 运行时动态写 CSS 文本
│     ① 变量覆盖：html[data-xs-mode] 下同时覆盖 Semi 变量 + shadcn 变量
│     ② 玻璃规则：容器半透明 + backdrop-filter(仅静态容器)
│     ③ 可读性：根据底色自动给 text-* 取黑/白
└─ React 树
      └─ 设置·通用页 $D → 新增"外观/主题替换"卡片 → 调 XSTheme API（实时预览/应用/保存/重置）
```

> **为什么需要自建 `#xs-backdrop` 背景层（重要，避免踩坑）**：Electron 窗口默认不透明，`backdrop-filter` 只能模糊"窗口内其下方的像素"，并不能直接模糊 Windows 桌面。因此内置一层随主色变化的氛围渐变（图片主题时为模糊后的图片）作为玻璃后方景色，即可得到稳定的"真磨砂玻璃"观感，且**纯前端、第 2 天就能交付**。若老板要"透出桌面"的毛玻璃，则必须由主进程把 `BrowserWindow` 设为透明/材质（列入 §8 需中央项，不阻塞默认方案）。

## 3. CSS 变量覆盖策略（双体系一起换）

### 3.1 挂载与层叠优先级

- 注入样式放在 `document.head` **最后**；选择器统一加前缀 `html[data-xs-mode]`（特异性 0,1,1 高于 `:root`/`.dark`/`body`），需要压过 Semi 内联变量时用 `html[data-xs-mode] body{…}`（特异性 0,1,2）。**不使用 `!important` 海**，只在个别 Semi 组件内联兜底处定点使用。
- 明暗不另起炉灶：沿用现有 `html.light/.dark`（§1.2）。主题层只决定"在当前明暗下，玻璃底色/主色如何取"，切换明暗由现有逻辑负责，主题层监听 html class 变化（`MutationObserver`）即时重算，保证深/浅两套都协调。

### 3.2 主色：一次生成 0–9 色阶，同时喂给两套体系

用户调的是一个主色 `primary(HEX)`。运行时把它转 HSL，向 L 增大/减小方向插值出 10 级色阶（参考 Semi 蓝阶明度分布），然后：

- **Semi（改通道最彻底，改语义最稳，两者都做）**
  - 通道：覆盖 `--semi-blue-0..9`（Semi 的 primary 默认绑 blue；同步覆盖 `--semi-color-link / focus-border` 等绑 blue 的语义，避免漏色）；
  - 语义兜底：`--semi-color-primary / -hover / -active / -disabled-light / -disabled` 直接给计算好的 rgba，保证 Select/Button/Switch/高亮 全部跟随。
- **shadcn**：覆盖 `--primary` 与 `--ring`（同一主色 HSL 三元组）、`--primary-foreground`（主色上的文字，按对比度自动取黑/白）。
- 辅助色 `secondary/accent`：由主色同色相低饱和派生，保证全局协调而不杂乱。

### 3.3 背景 / 表面 / 文本（玻璃化的核心）

- shadcn：把 `--card/--popover/--background/--secondary/--muted/--accent` 改为"带 alpha 的表面色"（alpha 由玻璃强度滑杆控制），`--foreground/--card-foreground/--muted-foreground/--border/--input` 按当前明暗重算，保证文字对比。
- Semi：把 `--semi-color-bg-0..4` 改为半透明表面、`--semi-color-fill-0..2`、`--semi-color-border` 改为半透明白/黑描边，`--semi-color-text-0..3` 做可读性矫正。
- 复用现成 `--floating-*` 变量同风格赋值，让浮窗/全局观感一致。

### 3.4 玻璃作用范围与性能边界

- **玻璃化（半透明 + backdrop-filter: blur+saturate）**：侧栏、顶栏/标题栏、设置卡片与面板、弹窗/下拉/气泡（Semi Modal/Dropdown/Tooltip/Popover）、输入区容器、会话顶部栏。
- **只半透明、不加 blur**：会话消息流/长列表滚动区（大面积 backdrop-filter 在滚动时吃 GPU，易掉帧），其底色由 `#xs-backdrop` 透出，视觉仍是玻璃但不卡。
- blur 半径默认 16px（可调 0–30），`saturate(1.4)` 提色，圆角、1px 内高光描边（`inset 0 1px 0 rgba(255,255,255,.12)`）增强玻璃边缘；对玻璃容器加 `will-change/transform:translateZ(0)` 仅在开启动画时短暂使用，避免常驻显存。
- 提供"玻璃总开关 / 玻璃强度 / 模糊半径 / 色调浓度"，低端设备可一键切到 `flat`（纯色换肤、零 blur 开销）。

## 4. 磨砂玻璃主题（可调色、实时预览、记忆、恢复）

- **可调主色**：预设色板（玄枢冰蓝/玄青/赤焰/紫宸/墨玉等若干）+ 原生取色器 + HEX 输入（带校验），三路任一改动都经 `requestAnimationFrame` 节流后只做 `CSSStyleDeclaration.setProperty`（**不触发 React 重渲染**），做到拖动实时跟手、无明显卡顿。

## 5. 图片生成主题（纯前端 Canvas，零依赖、不上传）

流程：选图 → 降采样 → 背景/主色/辅色分离 → 量化选色 → 可读性矫正 → 生成整套色阶 → 预览 → 应用/保存。

1. **读取与降采样**：`URL.createObjectURL` → `Image` → 绘到 ≤64×64 离屏 canvas（抗噪、降算力），`getImageData` 取像素。全程本地，不发网络（符合"不向厂商云发流量/纯本地"红线）。
2. **背景色分离（避免被花图带偏）**：对**边缘一圈**像素（上下左右各取 8% 宽条）在 RGB 空间做众数聚类，得到背景色 `bg`；后续主色选举时对"与 bg 色距过小"的像素降权。
3. **主色/辅色选举（自实现量化，不引库）**：对**内部区域**像素先过滤——剔除近灰（饱和度过低）、极暗/极亮（明度两极）、以及近背景像素；剩余像素用 HSL 分桶（H 16 段 × S 4 段 × L 4 段）做加权直方图，权重 = 像素占比 × 饱和度系数 × 中心权重。桶内取加权平均色得到候选；主色 = 权重最高且明度落在可用区间者；辅色 = 与主色色相间距 > 40° 的次高候选（找不到则取主色互补/邻近派生）。
   - 用 HSL 分桶而非全量 K-means，是为了**结果稳定、可复现、代码小、无依赖**；如中央更倾向中位切分/MMCQ，可在不引依赖前提下替换选举内核（接口不变）。
4. **文本可读性自动矫正（WCAG）**：用相对亮度 `L=0.2126R+0.7152G+0.0722B`（线性化后）计算对比度；主色按钮文字、卡片标题/正文分别要求对比度 ≥ 4.5 / ≥ 3，不达标自动向黑或白平移；同时给 `--*-foreground` 系列定值。
5. **生成整套主题**：以主色生成 §3.2 的 0–9 色阶与双体系变量；背景层 `#xs-backdrop` 使用"图片放大模糊 + 主色渐变叠罩"，玻璃表面主色取自提取结果，形成"图与色一致"的整套主题。
6. **预览/应用/保存**：先预览（只改当前会话样式），"应用"才持久化；保存记录图片名、提取时间、四色（primary/secondary/bg/text）与派生变量；可保存多套图片主题到预设列表，随时切换/删除。
7. **健壮性**：图片加载失败、跨域、纯色图、全灰图都有兜底（退回主色手调模式，不报错、不白屏）。
