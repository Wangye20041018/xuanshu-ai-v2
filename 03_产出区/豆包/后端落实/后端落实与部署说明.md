## 二、真实链路原理

### 三档模型来源（改的是网关真正读取的默认模型）
配置 `~/.openclaw/openclaw.json` 的 `agents.defaults.model = { primary:"provider/model", fallbacks:[...] }` 决定对话默认路由：
- **本地 local**：`primary = local-qwen/<模型>`，拉起内嵌 llama-server(127.0.0.1:8082)，无 fallback；
- **云端 cloud**：`primary = token-cloud/...`（切离本地时自动记住你原来的云端选择，切回即还原），fallback 不含本地；
- **自动 auto**：`primary = 本地`、`fallbacks=[云端]`——本地优先、失败自动兜底云端。
写入优先走 `GatewayConfigRuntimeSync.mutateAndWait`（运行中网关立即生效），异常时回退文件写入。

### 语云语音（全离线）
按住说话 → asr_api 16kHz/单声道录音 → 松开落盘 WAV → `asr:transcribe` → 主进程懒启动便携 Python 常驻进程加载 Paraformer（仅首次约 13s）→ 之后每条 0.2~0.3s 出文字 → 回填输入框。
