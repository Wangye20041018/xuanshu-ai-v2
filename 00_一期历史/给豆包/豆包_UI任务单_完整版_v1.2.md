## 6. UI 全局设计规范（玻璃态 · 字体 · 首页 · 功能页）

### 6.0 总方针（一句话）
以 **Trae（字节 AI IDE）的视觉风格为参照蓝本**，做融入玄枢定位的本土化全局 UI 重设：全局磨砂玻璃态主题、去花哨、字体统一、首页对话体验重点打磨。**不是硬抄**——允许改、移、删、增、整合。每个小部分仔细核对，做到**神似形也似**。
**严禁**：花里胡哨、发光/炫光渐变、霓虹、大面积高饱和配色、非必要动画堆砌。要克制、高级、专业、信息密度高的"本地算力终端"气质。

### 6.1 A 类 · 全局玻璃态主题（先做，定调）
1. 主窗口/侧边栏/顶栏/浮层/面板统一**半透明磨砂玻璃**（`backdrop-filter: blur(...)` + 半透明白/黑底 + 1px 高光内描边）；深/浅两套玻璃参数都要好看、低对比不刺眼，默认深色；磨砂后文字必须有足够对比度。
2. 布局重排（参照 Trae 三栏式骨架，按玄枢实际功能取舍）：侧边栏 / 主工作区（聊天首页）/ 右侧工作面板逐块评估保留、整合、删除；间距/圆角/阴影层级全局 token 化（一个 design token 文件，禁止散落魔数）。
3. 窗口设计：标题栏、无边框/半透明策略、最小/最大/关闭控件风格统一；多窗口/浮球风格一致。
4. 去花哨：全局 scan 移除发光按钮/彩色渐变/跳动动效/霓虹阴影；动效只留 120~200ms 轻反馈且尊重系统减弱动效。
5. **视觉辅助（必用）**：对每个页面截图 → 对参照物截图 → 逐块对比标注差异 → 实施 → 改后再截图自查；**每页"改前/改后"截图成对存档**进交付说明。

### 6.2 B 类 · 字体体系统一（全局 token 化）
1. 统一字体 token（`fonts.ts`/theme）：标题/正文/辅助/代码各自字体栈、字号/字重/行高/字间距；中英文混排规范。
2. **对话字体统一（重点）**：AI 回复与用户消息同字体体系、同语感，仅内容归属/底色区分。
3. **功能页字体统一**：设置/模型管理/智能体/自检等页同一套 token。
4. 代码块用统一等宽字体，语法高亮低饱和融入玻璃主题。

### 6.3 C 类 · 首页（聊天）双方交互（重点中的重点）
1. 消息气泡：用户 vs AI 布局、对齐、间距、底色玻璃层级、圆角、头像/标识体系统一；突出"任务与结果"的信息结构（算力终端非拟人）；时间戳/角色标识清晰不抢眼。
2. **AI 回复格式强化**：Markdown 排版规范（标题/列表/引用/表格/分隔线）；代码块+复制按钮+可选行号+语言标签；深度思考折叠条样式规范化（思考段≠正文）；长回复分节/目录/折叠；工具调用/动作展示的可视化（动作+结果摘要，不灌 trace）；tokens/耗时/模型名小字弱化真实显示（ContextStats 冻结项勿回退）。
3. 输入框模块重排：功能模块分组/顺序/去重/增删，融入玻璃输入框；**删除"智能体编排"按钮**；输入框玻璃态 + 发送按钮样式升级。
4. 空态：无会话/无消息空态升级，不假数据。

### 6.4 D 类 · 功能页与功能按键
1. 功能页整合取舍：结合 Trae 蓝本逐页评估——可整合（模型页+设置关联）、可删（与设置重合项、语音页、软件操控页）、可增（智能体管理/总调度/自检/模型管理页）。**禁止死链接与"已删但入口还在"半成品。**
2. 功能按键统一风格：主/次/危险按钮尺寸、圆角、玻璃层级、禁用态、hover 态全局一致；图标统一线宽。
3. 设置页：删重合项；自检做成专业健康模块。
